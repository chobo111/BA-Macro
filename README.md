# BA Macro

Windows용 Python + PySide6 매크로 앱입니다. 단축키로 커서를 이동하거나 스크립트를 독립 터치로 실행합니다.

## 설치 및 실행

Windows 10/11과 Python 3.10 이상이 필요합니다.

1. 이 저장소를 내려받아 압축을 풉니다.
2. `launch.cmd`를 실행합니다. 처음에는 가상환경과 필요한 라이브러리를 설치하므로 인터넷 연결이 필요합니다.
3. 이후에는 생성된 `BA Macro.lnk` 바로가기로 실행합니다.

폴더를 옮겼다면 `launch.cmd`를 다시 실행해 바로가기를 갱신하세요.

## 기본 사용법

1. **대상 앱** 목록에서 실행 중인 앱을 선택합니다.
2. 행을 선택하고 원하는 위치에 커서를 놓은 뒤 `Ctrl+S`로 좌표를 가져옵니다.
3. 행의 단축키와 동작을 지정합니다.
   - **커서 이동**: 저장된 좌표로 실제 커서를 이동합니다.
   - **스크립트**: ‘스크립트 작성’에서 명령을 입력하고 저장합니다. 실행 시 실제 커서를 움직이지 않는 독립 터치를 사용합니다.
4. 재생 버튼이나 Ctrl+백틱으로 활성화한 뒤, 대상 앱에 포커스를 두고 행 단축키를 사용합니다. 같은 버튼이나 단축키로 정지합니다.

단축키와 동작 설정은 ☰ → 환경설정에서 변경할 수 있습니다. 메모 열 경계를 드래그하면 표 너비도 함께 조절되며, 창을 넓혀도 표가 자동으로 늘어나지는 않습니다.

## 프로필과 좌표

- 표의 변경사항은 자동저장됩니다. 스크립트 초안은 편집창에서 **저장**을 눌러 적용합니다.
- ☰ 메뉴에서 프로필을 생성·불러오기·복제·이름 변경할 수 있습니다. **프로필 선택 → 이 폴더**에는 현재 프로필 폴더의 프로필이 표시됩니다.
- 개인 설정과 프로필은 로컬 JSON 파일에 저장됩니다. 소스 업데이트 전에는 별도로 백업하세요.
- 좌표는 대상 앱의 내부 영역을 기준으로 합니다. 앱 크기가 프로필 기준과 다르면 시작 시 창 크기 변경 또는 자동 변환을 선택할 수 있습니다.
- 수동 좌표 변환은 ☰ → **프로필 해상도 변환**에서 실행합니다.

## 스크립트

한 줄에 명령 하나를 작성하며, 시간 단위는 ms입니다. `mouse`는 명령 실행 시점의 커서 위치를 사용합니다.

```text
loop
click mouse
sleep 100
loop_end
```

`loop` 또는 `loop until_release`는 단축키를 누르는 동안 반복합니다. 대상 앱 영역에서 우클릭하면 편집 위치에 좌표가 들어갑니다. 명령어와 제한사항은 편집창의 **?** 도움말에서 확인할 수 있습니다.

독립 터치는 대상 앱이 터치 입력을 지원해야 합니다. 대상 앱이 포커스를 잃거나 터치 위치가 다른 창에 가려지면 실행이 중단될 수 있습니다.

## 개발

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

폴더형 EXE 빌드:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller BlueArchiveStudio.spec
```
