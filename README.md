# BA Macro

Python + PySide6로 새로 작성한 Windows용 좌표·단축키 매크로입니다.
기존 Tkinter 구현을 사용하지 않습니다. 기존 프로그램의 JSON 좌표 프로필을 읽을 수 있습니다.

## 실행

Windows 10/11, Python 3.10 이상(개발 검증: Python 3.12)이 필요합니다.
**`BA Macro.lnk` 바로가기를 두 번 클릭하면 검은 콘솔 창 없이 실행됩니다.**
처음 설치할 때는 `launch.cmd`를 실행하세요. 전용 `.venv`와 라이브러리를 설치하고 바로가기를 만듭니다. 최초 설치에는 인터넷 연결이 필요합니다.
폴더를 옮겨 바로가기 경로가 달라지면 `launch.cmd`를 다시 실행하거나 `create-shortcut.ps1`로 바로가기를 재생성하세요.
이미 설치된 Python 또는 이 PC의 Codex Python 런타임을 찾습니다.

직접 실행할 수도 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

실행 중에 바로가기를 다시 열면 기존 창을 앞으로 표시합니다. 트레이에 숨겨졌거나 최소화된 창도 복원합니다.
작동 전환 버튼은 정지 상태에서 빨간색과 재생 아이콘, 활성화 상태에서 녹색과 정지 아이콘을 표시합니다. 버튼 문구에는 환경설정의 작동/정지 단축키를 표시하며, 단축키 변경 시 즉시 갱신합니다.
대상 앱과 입력 제어 권한이 다르면 입력이 거부될 수 있으며, 오류를 상태 표시줄에 표시합니다.

## 사용 순서

1. 대상 게임 또는 에뮬레이터 창을 선택합니다. 목록을 펼칠 때마다 창 목록을 갱신하며, 동명 창은 창 핸들로 구분합니다.
2. 행을 선택하고 캡처할 위치에 커서를 놓고 기본 `Ctrl+S`로 좌표를 캡처합니다.
3. **단축키** 버튼을 누르면 별도 지정 창에서 편집합니다. 중복 입력은 기존 값을 유지하고 4초간 로그로 알립니다. 공통 좌표 캡처 키는 환경설정에서 변경합니다.
4. 동작 모드를 선택하면 변경사항이 즉시 자동저장됩니다.
5. **작동 시작**을 누르고 대상 창에서 실행 키를 사용합니다. 기본 작동/정지 키는 Ctrl+백틱입니다.

앱은 정지 상태로 시작하며 기본 선택은 **미선택**입니다. 미선택 상태에서 시작하면 프로필에 기록된 앱을 다시 찾아 자동 선택하고 기존 해상도 확인 절차를 거쳐 시작합니다. 앱이 실행 중이지 않거나 일치하는 창을 구분할 수 없으면 앱 선택 안내를 표시합니다. 미선택 상태의 좌표 캡처는 앱 또는 전체화면 선택 안내를 표시합니다. **전체화면**을 직접 선택하면 기존처럼 창 지정 없이 좌표 클릭·커서 이동과 좌표 캡처가 가능하며, 여러 모니터를 포함한 화면 절대 좌표(음수 좌표 포함)를 사용합니다. 환경설정에서 작동 디스플레이를 선택하면 해당 모니터 기준으로 동작합니다. 프로필에 저장된 앱이 실행 중이면 기존처럼 실행·불러오기 시 자동 복원하고, 찾을 수 없으면 미선택을 유지합니다.
특정 창을 선택하면 해당 창의 내부 좌표를 사용하며, 그 창이 활성화된 동안 실행합니다. Ctrl+S 좌표 캡처는 포커스와 무관하게 작동하며, 커서는 대상 창의 내부 좌표 범위 안에 있어야 합니다. 자동 중지 옵션(기본 ON)이 켜져 있으면 프로필 편집이나 설정 창 열기 시 일시정지됩니다. OFF에서는 작동 준비 상태를 유지합니다.
일시정지 중에도 작동/정지 단축키는 유지됩니다. 핀·작동 버튼은 왼쪽 기준 고정 위치이며, 좌표 표시 폭도 고정입니다.

### 실행 모드

| 모드 | 동작 |
|---|---|
| 좌표 클릭 | 저장 좌표로 이동해 왼쪽 클릭 후 실행 직전 커서 위치로 복귀 |
| 커서 이동 | 저장 좌표로 이동 |
| 스크립트 실행 | 스크립트 작성 버튼에서 작성한 명령을 독립 터치로 실행 (앱 선택 필요) |

좌표 클릭과 커서 이동은 키를 길게 눌러도 한 번 누를 때 한 번만 실행됩니다. 스크립트는 `loop` 구문으로 반복을 지정합니다.
키를 놓으면 진행 중인 반복을 마친 뒤 멈추고, 일시정지는 진행 중 대기도 중단합니다.
입력은 하나의 작업 스레드에서 처리하며 마지막에 누른 단축키를 우선 실행합니다.
다른 단축키를 누르면 기존 동작의 반복·대기를 중단하고 누른 입력을 해제한 다음 새 동작을 실행합니다.
전환 중 여러 요청이 들어오면 아직 시작하지 않은 요청은 가장 최근 요청으로 교체합니다.
중단된 스크립트의 `release_actions`는 실행하지 않으며, 1번 키를 계속 누르고 있어도 자동 재개하지 않습니다.
1번을 다시 실행하려면 키를 놓았다가 다시 누르세요. 단축키 조합은 보조키를 먼저 누른 뒤 일반 키를 누릅니다.
특정 창을 대상으로 사용할 때 다른 창으로 전환하면 현재 동작을 취소합니다. 다음 실행은 키를 놓았다가 다시 누르세요. 전체화면 모드는 창 전환에 관계없이 실행됩니다.

### 편집 및 부가 기능

새 프로필은 Q/W/E 3행과 빈 메모로 시작합니다. 기존에 저장된 프로필의 행과 메모는 유지됩니다.
창은 처음 표 너비에 맞춰 열리며, 최소 400×340에서 가로·세로 크기를 자유롭게 조절할 수 있습니다(Qt 논리 픽셀 기준).
메모 열은 창 안의 남는 공간을 사용하며 긴 내용을 입력해도 창이나 상단 버튼이 늘어나지 않습니다. 전체 내용은 메모 위에 마우스를 올려 확인할 수 있습니다. X/Y 입력 칸은 동작 모드와 관계없이 숫자 5자리 기준 너비를 유지합니다.
동작은 짧은 이름으로 표시하고 마우스를 올리면 전체 설명을 볼 수 있습니다.
실시간 커서 좌표는 핀 버튼 왼쪽과 스크립트 작성 창에 항상 표시됩니다. 핀 아이콘은 활성화 시 파란색으로 바뀝니다.
저장 확인 창은 **저장 / 저장 안 함 / 취소** 버튼을 사용합니다.

- 좌표 직접 입력, 메모 편집, 행 추가·다중 삭제, 메모 셀 드래그로 단일 행 이동
- 기존 JSON 프로필 열기, 새 프로필, 저장, 다른 이름으로 저장
- 파일 → 프로필 이름 변경: 같은 폴더에서 JSON 파일명과 다음 실행 시 불러올 파일을 함께 변경합니다. 같은 이름의 파일은 덮어쓰지 않습니다.
- 정보 → 현재 프로필 정보: 파일 위치, 지정 앱, 기준 크기, 현재 선택과 크기, 동작 수, 자동 변환 및 저장 상태를 확인합니다.
- 자동저장 실패 시 변경사항을 유지하고 새 파일/열기/종료 시 저장 여부 확인
- 대상 창 크기: 16:9 / 4:3 비율별 해상도 프리셋 또는 직접 입력, 해상도 비율에 따른 좌표 변환
- 클릭 전/후 대기, 클릭 유지 시간, 설정·편집 시 자동 중지 설정
- Dark / Light / System 테마, 실시간 좌표, 창을 다시 표시하지 않는 **항상 위** 토글 버튼, 트레이 최소화
- 전역 단축키 충돌 검사, 처리한 키의 선택적 전달 차단(기본 켜짐)

프로필 변경 내용은 즉시 자동저장합니다. 메모는 입력하는 동안 저장하며, 스크립트는 편집기의 저장을 눌러 확정하면 자동저장합니다. 선택 삭제 옆의 저장 버튼은 제거했고 파일 메뉴의 저장은 유지합니다. 파일 → 새 프로필은 저장 창에서 이름과 위치를 지정합니다. 취소하면 현재 프로필을 유지하며, 기존 파일을 고르면 저장 창에서 덮어쓰기를 확인합니다. 전역 설정은 **프로그램과 같은 폴더의 `setting.json`**에 저장합니다.
실행 시 `last_profile` 파일명을 읽어 같은 폴더에서 최근 프로필을 불러옵니다.
정보나 파일이 없으면 `macro.json`을 사용하고, 이 파일도 없을 때만 Q/W/E와 빈 메모로 생성합니다.
기존 `macro.json`은 덮어쓰지 않습니다. 외부 폴더의 프로필은 프로그램 폴더에 복사해 다음 시작 때 사용하며,
같은 이름의 파일이 있으면 `_1`, `_2` 등을 붙여 보존합니다. 저장하지 않은 편집은 복사본에 반영하지 않습니다.
기존 로컬 앱 데이터 폴더의 `settings.json`은 자동으로 가져오지 않습니다.
프로필 저장은 임시 파일에 쓴 뒤 원자적으로 교체합니다.

### 스크립트 작성

스크립트는 독립 터치 입력만 사용합니다. 입력 방식 선택 설정과 기존 물리 마우스 스크립트 경로는 제거했습니다.
Windows 10 1809 이상이 필요합니다. 스크립트는 앱을 선택하고 해당 앱에 포커스를 둬야 실행되며, 터치 좌표가 다른 창에 가려지면 중단합니다. 전체화면에서 스크립트 단축키를 누르면 입력을 보내지 않고 하단 로그에 “스크립트를 실행하려면 앱을 선택하세요.”를 4초간 표시합니다. 이 안내만으로 작동 상태를 정지하지 않으며 일반 좌표 동작은 전체화면에서도 사용할 수 있습니다.
좌클릭·이동·드래그를 지원합니다. 키보드·문자 입력과 left 이외의 버튼 명령은 저장·실행 시 오류로 안내합니다.
일반 동작의 좌표 클릭·커서 이동은 실제 마우스를 사용하는 기존 동작을 유지합니다.


편집기는 메인 창과 크기가 동기화되며 작성방법 사이드바 없이 표시됩니다. 편집기 우측 하단을 끌어 크기를 조절하면 메인 창에도 반영됩니다. 편집기는 메인 창 메뉴 아래의 본문과 하단 로그바를 덮습니다. 메인 타이틀바와 파일·설정·정보 메뉴는 그대로 사용할 수 있으며, 창 이동은 메인 타이틀바를 이용합니다. 편집기 자체 드래그 영역은 없습니다. 배경은 어둡게 표시하지 않습니다. 패널과 메인 프로그램 창 밖을 우클릭하면
현재 편집 위치에 `x,y`만 삽입됩니다(명령이나 줄바꿈은 추가하지 않습니다). 대상 창을 지정했다면 그 창 내부의 좌표만 허용합니다. 현재 앱 크기와 프로필 기준 크기가 다르면 기준 크기로 역변환한 좌표를 삽입하므로, 자동 변환 실행 중이거나 편집을 위해 자동 정지한 뒤에도 같은 기준으로 작성할 수 있습니다. 캡처 이후 앱 크기가 바뀌면 다시 캡처해야 저장할 수 있으며, 편집 중 프로필 또는 기준 크기가 바뀌면 편집기를 다시 열어야 합니다.
편집기는 화면 전체를 덮지 않아 외부 좌클릭으로 다른 프로그램을 사용할 수 있습니다. 편집 중 외부 우클릭만 좌표 입력으로 처리하며, 편집기를 닫으면 처리가 해제됩니다. 도움말·대화상자·메뉴가 열려 있는 동안에는 외부 우클릭을 다른 앱에 그대로 전달하고, 닫으면 좌표 캡처를 재개합니다.
문법은 저장 시 검사합니다. 오류는 편집기 하단에 4초간 표시되며 편집기를 닫지 않습니다. 평상시에는 편집기 로그 영역을 숨깁니다. 취소 또는 Esc는 확인 없이 변경을 버리고 닫습니다. 저장은 입력을 실행하지 않습니다.

```text
// 단축키를 누르는 동안 반복
loop
    click mouse
    sleep 100
loop_end
```

`loop 3`은 3회 반복, `loop`는 단축키를 놓을 때까지 반복합니다.
이전 `loop until_release` 문법은 삭제되었으므로 기존 스크립트에서는 `loop`로 바꾸세요.
`release_actions` 아래는 단축키를 뗀 뒤 실행합니다.
좌표의 `mouse`는 각 좌표 명령 실행 시 읽는 현재 실제 커서 위치입니다. 반복 중에도 갱신하며 한 번의 `curve` 경로는 시작 시 정한 좌표를 유지합니다. `click`의 여러 좌표는 순서대로 클릭하며 멀티터치가 아닙니다.
일반 누름은 실행 완료 시 해제되고, `switch` 입력은 다음 전환·명시적 해제·일시정지·종료까지 유지됩니다.
컨트롤러와 MuMu 전용 조준 모드는 지원하지 않습니다. 편집기에서 예제를 선택해 기존 내용을 덮어쓰고 저장 시 문법을 확인할 수 있습니다.
프로필 좌표 변환은 표의 X/Y와 스크립트의 숫자 좌표에 적용되며 mouse와 시간 값은 유지합니다.

대상 창은 실행할 때 다시 선택합니다. 이전 프로세스의 창 핸들을 재사용하지 않습니다.

## 개발 구조

- `app.py`: 메인 화면 조립, 확인창과 사용자 작업 연결, Qt 신호로 실행·저장 결과 수신
- `execution_plan.py`: 승인된 실행 기준과 명령 생성. 준비 결과는 저장과 검사 후 실행 세션에 한 번에 반영
- `coordinate_transform.py`: 파일 변환과 메모리 변환이 공유하는 좌표 범위·반올림 규칙

### 드래그 속도

설정 → 환경설정 → 동작 / 스크립트의 **curve 드래그 시간**에서 `curve`의 이동 시간을 조절합니다.
기본값은 10ms이며 0~99,999ms를 지원합니다. 세 좌표는 두 구간이므로 이동 시간도 두 번 적용됩니다.
`curve_first_time`, `curve_last_time`, `sleep`의 대기 시간은 별도입니다.
짧은 이동 시간은 중간 좌표 수를 줄여 불필요한 대기를 줄입니다. 0ms는 즉시 이동합니다.
실제 시간과 게임이 인식하는 입력 빈도는 Windows 스케줄링과 대상 프로그램에 따라 달라집니다.
`setting.json`의 설정 이름은 `drag_segment_duration_ms`입니다. 기존 설정에 이 항목이 없으면 10ms를 사용합니다.
단축키 전달 차단의 기본값은 켜짐이며, 사용자가 저장한 켜짐/꺼짐 선택은 유지됩니다.

처음 앱을 지정하면 프로필 JSON의 target_program에 실행 파일명(전체 경로 제외), 창 클래스, 제목을 자동저장합니다. 이후 다른 앱이나 전체화면을 선택해도 기존 기록은 시작을 승인할 때까지 유지합니다. 다음 실행이나 프로필 불러오기 때 기록된 앱을 찾아 자동 선택하며, 일치하는 창이 여러 개로 모호하면 자동 선택하지 않습니다. 앱 목록을 열어 새로고침할 때는 현재 선택을 유지합니다. 선택한 앱이 사라졌다면 미선택으로 돌아가고 정지하며 다른 앱을 대신 선택하지 않습니다. 작동은 정지 상태로 시작합니다.

행 추가는 + 버튼, 선택 삭제는 쓰레기통 아이콘입니다. 예제는 스킬 카드 → 마우스 슬라이드, 마우스 → 스킬 카드 슬라이드, 좌표 → 좌표 슬라이드 세 가지이며 X,Y를 실제 좌표로 바꾼 뒤 저장하세요. 저장은 스크립트 실행을 시작하지 않습니다. 기존에 지정한 작동/정지 단축키는 새 기본값으로 덮어쓰지 않습니다.

새 행의 메모는 비어 있습니다. 메인 로그 안내는 4초 후 사라집니다. 스크립트 편집기의 별도 제목·드래그 영역과 행·열 위치 표시는 제거했습니다.

## 리팩토링 브랜치

`refactor/state-and-persistence`에서는 변경 즉시 프로필 스냅샷을 저장 큐에 넣습니다. 실제 파일 쓰기는 단일 작업 스레드가 순서대로 처리하며 완료 전까지 변경 표시를 유지합니다. 새 프로필 전환·불러오기·종료 시 대기 중인 저장을 확인합니다. 프로필 저장 성공과 설정/최근 프로필 정보 저장 실패는 별도로 표시합니다. 환경설정은 값이 바뀌었을 때만 기록합니다.

스크립트 실행 요청은 문법 검사에서 만든 불변 Program을 실행기에 전달하므로 같은 요청을 두 번 컴파일하지 않습니다. 지원하지 않는 설정 항목이 있으면 불러오기 오류로 안내합니다. 공개 매크로 동작·문법은 유지합니다.

행 삭제 후에는 첫 삭제 행 바로 위의 남은 행을 선택합니다. 맨 위 행 삭제 시 새 첫 행을 선택하며, 단축키 미지정 버튼은 공란입니다. 스크립트 편집기 도움말 버튼에서 전체 명령어와 문법을 확인할 수 있습니다. 크기 조절 핸들은 편집기의 우하단 가장자리에 있습니다. 정보 → 프로그램 정보에서 현재 버전을 확인합니다. 과거 변경 기록은 소스의 version.py에 보존합니다.

대상 창 복원은 실행 파일명(대소문자 무시)과 창 클래스로 후보를 찾고 제목으로 구분합니다. 같은 조건의 창이 여러 개라 특정할 수 없으면 자동 선택하지 않습니다. JSON의 exe에는 실행파일명만 허용하며 전체 경로는 지원하지 않습니다.

## 프로필 해상도 변환

설정 → **프로필 해상도 변환**에서 현재 프로필의 표 좌표와 스크립트 숫자 좌표를 함께 변환합니다. 다른 사람이 만든 파일은 먼저 불러온 뒤 이 메뉴를 사용하세요.

- 원본은 프로필의 `target_resolution`을 사용합니다. 알 수 없는 파일은 제작 당시 해상도를 직접 입력해야 합니다. 현재 창 크기로 임의 추정하지 않습니다.
- 대상은 선택한 창의 실제 내부 크기로 시작합니다. 대상 창이 없으면 직접 입력하며, 두 해상도 모두 16:9 / 4:3 프리셋을 지원합니다.
- 좌표별 미리보기 없이 변경 개수, 스크립트 오류와 원본 범위 초과를 안내합니다. 오류가 있으면 저장할 수 없습니다.
- `click`, `move`, `press`, `release`, `switch`, `curve`의 숫자 좌표를 변환합니다. 비활성 동작에 보관된 스크립트도 포함합니다. `mouse`, 시간, 반복 횟수, 주석과 줄바꿈은 유지됩니다. 현재 지원하지 않는 명령이 있으면 변환 전에 오류로 안내합니다.
- 기본 버튼 **변환본으로 저장**은 `원본명_너비x높이.json`을 제안하고 기존 파일이 있으면 번호를 붙입니다. 저장 후 변환본으로 전환합니다. 원본에 덮어쓰려면 **현재 프로필에 적용**을 선택하세요. 취소/파일 저장 실패 시 현재 프로필을 바꾸지 않습니다.
- 비율 차이는 변환을 차단하지 않습니다. 원본·현재 창 각각의 가로 정수화 오차를 최대 1px 고려하고, 그 범위를 넘으면 경고를 표시합니다. 1920×1080 → 1835×1032는 비율 경고 없이 변환하며, 1280×960처럼 차이가 큰 경우에는 경고를 확인한 뒤 자동 실행 또는 수동 저장을 진행할 수 있습니다. 좌표 계산은 기존처럼 X/Y에 각 크기의 배율을 적용합니다. 게임 UI 재배치나 여백은 보정하지 않습니다. 음수 또는 원본 크기 밖의 좌표는 여전히 오류입니다.
- 대상 창 크기 변경이 확인되고 변환 옵션이 켜져 있으면 실제 변경된 크기로 변환 화면을 엽니다. 표의 좌표 캡처 시 해상도가 다르거나 기존 좌표의 기준이 불명확하면 먼저 변환을 안내합니다. 스크립트 편집기는 앱을 선택한 상태에서 현재 크기가 프로필 기준과 다르면 우클릭 좌표를 기준 크기로 역변환하여 추가합니다. 기존 좌표와 프로필 기준 크기는 유지하며, 기준이 불명확하거나 앱 미선택 상태에서 크기가 다르면 먼저 변환을 안내합니다. 처음 만드는 빈 프로필은 최초 캡처 해상도를 기록합니다.

변환 자체는 원본의 복사본으로 계획하고 검증한 뒤 저장하므로 일부 좌표만 변경된 상태가 원본에 반영되지 않습니다. 빈 스크립트나 공백만 있는 스크립트는 변환 검사를 건너뛰며 행·단축키·빈 내용을 유지합니다. 내용이 있는 스크립트의 문법·좌표 검사는 그대로 수행하고 표 좌표는 빈 스크립트 행에서도 변환합니다.

## 작동 디스플레이 선택

환경설정의 **작동 디스플레이**에서 모니터를 선택할 수 있습니다. 모니터 모델명과 실제 픽셀 해상도를 표시하며 선택은 `setting.json`의 `display_id`에 저장합니다.

- 대상 창이 없는 전체화면 모드에서는 선택한 모니터의 왼쪽 위가 `0,0`입니다. 좌표 표시·캡처, 스크립트 우클릭 캡처와 좌표 클릭이 같은 기준을 사용합니다. 스크립트 실행에는 앱 선택이 필요하며 선택한 앱의 창 내부 좌표를 사용합니다. 해상도 변환 화면의 대상 크기도 해당 모니터 크기로 시작합니다.
- 대상 창을 선택하면 디스플레이 설정을 무시하고 해당 창 내부 좌표를 사용합니다. 선택한 모니터가 연결되지 않아도 다른 모니터의 대상 창은 사용할 수 있습니다.
- 선택한 모니터가 연결 해제되거나 배치·해상도가 변경되면 전체화면 실행을 중지합니다. 연결이 사라진 모니터를 다른 모니터로 자동 대체하지 않습니다.
- 기존 프로필 호환성을 위해 기본값은 **전체 디스플레이**입니다. 이 옵션은 기존의 바탕화면 절대좌표와 음수 좌표를 그대로 사용합니다. 특정 모니터로 변경할 때 기존 전체화면 좌표는 새 기준으로 다시 지정해야 합니다. 저장된 좌표는 설정 변경만으로 자동 변환하지 않습니다.

선택 목록은 환경설정을 열 때 갱신합니다. 모니터 번호는 앱의 목록 순서이며 Windows 디스플레이 설정의 식별 번호와 다를 수 있습니다.

환경설정은 일반 / 동작·스크립트 두 탭으로 구성하며 클릭 설정과 curve 설정 사이에 구분선을 표시합니다. 시간 설정 이름은 move_to_click_delay_ms, click_hold_ms, drag_segment_duration_ms이며 단위는 ms입니다. 현재 설정 이름만 지원하며 이전 이름은 자동 변환하지 않습니다.

좌표 클릭의 **클릭 후 커서 복귀 대기시간**은 버튼을 뗀 뒤 원래 커서 위치로 돌아가기 전의 대기입니다. 기본 50ms, 범위 0~99,999ms이며 설정 키는 `cursor_return_delay_ms`입니다. 커서 이동 모드와 스크립트에는 적용하지 않습니다. 중지하거나 다른 동작으로 전환하면 대기를 중단하고 복귀합니다.

**클릭 후 원래 커서 위치로 복귀** 옵션은 기본 켜짐입니다. 끄면 좌표 클릭 후 해당 위치에 머무르며 복귀 대기도 적용하지 않습니다. 시간 단위 ms는 숫자 입력칸 밖에 표시합니다.


## 시작 전 확인

시작 버튼과 작동/정지 단축키 모두 같은 확인을 거칩니다.

- 프로필에 기록된 앱과 현재 선택이 다르면 두 앱을 표시하고 **새 프로필 만들기 · 기본 Q/W/E 3행 / 새 프로필 만들기 · 현재 내용 복사 / 현재 프로필의 지정 앱 변경 / 취소** 중 처리 방법을 고릅니다. 선택 전에는 적용 버튼이 비활성화됩니다. 새 프로필은 원본을 보존하는 별도 파일에 저장한 후 정지 상태로 엽니다. 현재 프로필 변경은 좌표·스크립트·기준 해상도를 유지하고, 기존 크기 확인을 거쳐 지정 앱 저장에 성공한 뒤 시작합니다. 앱은 실행 파일명과 창 클래스로 비교하고 변경될 수 있는 창 제목은 실행 파일명을 읽지 못했을 때만 비교에 사용합니다.
- 앱 불일치 시 프로필 처리 방법은 항상 확인합니다. 이전 **다음부터 알리지 않음**과 환경설정의 앱 불일치 알림 옵션은 제거했습니다. 기존 `warn_app_mismatch` 저장 값은 보존하지만 확인창 생략에는 사용하지 않습니다.
- 프로필의 기준 해상도와 선택한 앱의 실제 내부 크기가 다르면 **창 크기 변경 / 자동 변환으로 시작 / 취소**를 표시합니다. 창 크기 변경은 실제 변경 결과를 검증하고 정지 상태를 유지하므로 다시 시작을 누릅니다. 자동 변환은 원본 좌표·스크립트·기준 해상도를 유지하며, 현재 크기에 맞춘 대체 좌표를 메모리에 캐시해 실행합니다. `mouse`는 현재 커서 위치를 그대로 사용합니다. 비율 차이가 정수화 오차 범위를 넘으면 좌표가 어긋날 수 있다는 경고를 표시하며 변환 버튼은 계속 사용할 수 있습니다.
- 프로필 해상도가 기록되지 않았으면 임의로 추측하지 않습니다. 앱 미선택 상태에서 특정 디스플레이를 지정했다면 크기 차이를 확인하되 프로필 좌표 변환만 제공합니다. 전체 디스플레이 모드에서는 창 크기 비교를 하지 않습니다.
- 다른 앱을 고르는 것만으로 프로필의 기존 앱을 덮어쓰지 않습니다. 앱·크기 확인을 통과해 시작하면 현재 앱을 기억하며, 승인한 전체화면 선택은 기존 앱 기록을 지웁니다.
- 다른 앱에서 좌표를 캡처해 저장할 때는 앱 지정 변경을 별도로 확인합니다. 승인하면 새 좌표와 앱 정보를 한 번에 저장하고 취소하면 모두 유지합니다. 시작 시 앱 불일치 알림을 꺼도 이 저장 확인은 유지합니다. 기존의 다른 좌표는 변환하지 않습니다. 스크립트 편집기의 캡처 좌표는 저장할 때 확인하며 취소하면 편집을 계속할 수 있습니다.
- 새 프로필은 자동 정지 설정과 관계없이 기존 실행을 정지한 뒤 만듭니다.

작동 시작 시 선택한 앱의 실제 내부 크기를 기록합니다. 실행 중 크기가 달라지면 정지하고 누르고 있던 클릭·터치를 해제하며 로그로 안내합니다. 화면 갱신 시와 새 동작을 제출하기 전, 실행기의 입력·대기·터치 유지 단계에서 검사합니다. 자동 정지 설정을 꺼도 이 검사는 유지하며, 창 위치만 이동한 경우에는 정지하지 않습니다. 원래 크기로 돌아와도 자동 재개하지 않으며 다시 시작해야 합니다. 프로필에 해상도가 없는 경우에도 시작 당시 크기로 감시합니다. 최소화·복원 중의 0×0 등 유효하지 않은 크기는 비교에서 제외하며, 기준 크기와 작동 대기 상태를 유지합니다. 유지 중인 클릭·터치는 해제하고 복원 후 새로운 단축키 입력으로 실행할 수 있습니다. 복원 후 실제 크기가 달라졌다면 정지합니다. 최소화된 앱으로 새로 시작하려 하면 창 복원 안내를 표시하고 시작하지 않습니다.

## 창 크기 조절

상단에 현재 창 내부 크기를 표시합니다. 16:9 / 4:3 버튼은 해상도 프리셋만 표시하고, 직접 입력은 너비 × 높이를 한 줄로 표시합니다. 비율 고정을 켜면 그 시점의 너비·높이 비율을 유지합니다. 입력칸과 닫힌 드롭다운은 휠로 값이 바뀌지 않습니다.

크기 변경은 SetWindowPos로 요청 크기를 적용한 뒤 Windows의 실제 크기 조절 모드(SC_SIZE)에 진입해 커서를 소폭 이동하고 원래 창 크기로 되돌리는 방식입니다. 0.2.27~0.2.29의 개별 갱신 알림 전송 실험은 제거했습니다. GetGUIThreadInfo로 실제 조절 모드 진입과 종료를 확인하고, 중간 크기 변화와 요청 크기 복귀는 창 내부 크기로 검사합니다. 위치나 테두리만 바뀐 경우에는 크기 불일치로 처리하지 않으며, 조절 전·복귀·종료 후 요청 크기가 두 번 연속 읽히는지 확인합니다. 실제 픽셀 크기의 허용 오차를 늘리는 변경은 아닙니다. 이 과정에서 대상 앱이 잠시 활성화되고 커서가 창 모서리로 이동합니다. 게임 화면에 클릭이나 키 누름을 주입하지 않으며 조절 모드 종료 확인 후 원래 커서 위치와 이전 포커스를 복원합니다. 사용자가 다른 앱으로 포커스를 옮긴 경우에는 포커스를 다시 빼앗지 않습니다.

마우스 버튼이 눌려 있거나 창이 최소화·최대화·응답 없음 상태인 경우, 크기 조절이 지원되지 않거나 모서리가 화면 밖인 경우에는 자동 드래그를 생략하고 로그로 안내합니다. 단계별 응답을 제한 시간 안에 확인하지 못하면 취소를 요청하고, 실제 내부 크기가 요청과 다른 경우에만 원래 창 크기 복원을 시도합니다. 실제 크기 차이가 남으면 요청·실측 크기를 안내하고, 복원에 성공한 경우에는 크기가 여전히 다르다는 경고 대신 복원 완료를 표시합니다. 조절 모드 종료를 확인하지 못하면 커서 이동이 창을 크게 바꿀 수 있으므로 강제 복귀하지 않고 Esc 종료를 안내합니다. 자동 드래그 실패 자체로 기본 크기 변경을 취소하지 않으며 기존 실제 크기 검증으로 최종 적용 결과를 확인합니다. 소스의 상태 처리와 실패 경로는 자동 테스트로 검증했지만 실제 게임의 선명도 개선 여부는 별도 사용자 검증이 필요합니다.

적용 전에는 실제 창 크기를 바꾸지 않습니다. 현재 크기와 같으면 적용 버튼을 비활성화합니다. 적용 후 최대 1초 동안 실제 크기를 확인하며, 요청 크기가 두 번 연속 확인되어야 성공으로 처리합니다. 거부·다른 크기 적용·창 종료는 화면 안에 안내하고 변환 창을 열지 않습니다.

변경 후 프로필 해상도 변환 체크 여부는 `setting.json`의 `resize_convert_profile`에 저장하며 기본값은 켜짐입니다. 창 크기 변경이 확인된 경우에만 선택에 따라 변환 화면을 엽니다.

스크립트 편집 중 환경설정과 정보 메뉴를 열어도 작성 내용은 유지됩니다. 파일 메뉴의 저장은 편집 중인 스크립트를 문법 검사 후 반영합니다. 새 프로필·불러오기·프로그램 종료 시 미확정 스크립트가 있으면 저장 여부를 확인하며, 편집기 자체 취소 버튼은 확인 없이 닫습니다. 프로필 해상도 변환은 수정 중인 스크립트를 먼저 저장한 뒤 엽니다.

실시간 커서 좌표는 메인 상단 메뉴 오른쪽에 공통으로 표시합니다. 메인 화면과 스크립트 편집 화면을 전환해도 같은 표시기를 사용하며, 편집기 안의 별도 좌표 표시와 갱신 타이머는 제거했습니다.


### 내부 처리 최적화

- 자동저장은 지연 타이머 없이 시작하며, 같은 파일에 대한 연속 요청 중 아직 시작하지 않은 저장만 최신 내용으로 합칩니다. 명시적 저장·다른 파일 저장·환경설정 저장의 순서는 유지하며 종료 시 대기 중인 저장을 마칩니다.
- 동일한 스크립트의 분석 결과는 최대 16개까지 재사용합니다. 스크립트 내용이 바뀌면 다시 분석하며 커서 위치·키 상태·실행 설정은 매 실행 시 새로 적용합니다.
- 실행할 작업과 대상 창에 유지 중인 입력이 없으면 실행 스레드는 알림을 기다립니다. 유지 중인 입력의 포커스 확인 주기와 클릭·드래그 대기시간은 유지합니다.

프로필 JSON은 명시적인 정수 `version: 3`과 `coords` 문자열을 사용합니다. 구형 버전, 별도의 x/y 필드, 삭제된 동작 이름 및 설정 항목은 지원하지 않습니다. 새 환경설정의 생략 항목에 기본값을 적용하는 기능은 유지합니다.

행은 메모 셀을 드래그해 이동합니다. 드래그한 행은 반투명하게 표시되며, 놓을 위치가 바뀌면 주변 행이 부드럽게 이동해 자리를 만듭니다. 위아래 가장자리에서는 자동 스크롤됩니다. 실제 순서와 자동저장은 드롭 시 한 번만 반영하고, Esc 또는 표 밖에서 놓으면 원래 순서를 유지합니다.

### 저장 파일 보호

프로필은 프로그램의 `setting.json`과 같은 파일에 저장할 수 없습니다. 대소문자·상대경로와 파일 별칭도 확인하며, 외부에서 가져온 같은 이름의 프로필은 별도 이름으로 복사합니다.
프로필 불러오기에 실패한 상태에서 해상도 변환을 적용하면 기존 원본 대신 새 파일에 저장합니다.
설정을 읽지 못하면 자동저장과 종료 시 원본을 보존합니다. 환경설정에서 직접 저장하면 원본을 `setting.invalid.bak`(기존 백업이 있으면 번호 추가)에 보관한 뒤 새 설정을 적용합니다.
숫자키와 방향키는 별도로 구분하며 숫자패드는 NumLock이 켜져 있으면 숫자, 꺼져 있으면 해당 탐색 키로 인식합니다.

외부 프로필의 최근 복사본은 직접 열거나 수정하면 독립 프로필로 보존합니다. 외부 원본을 다시 열 때는 새 이름으로 복사하며, 프로그램 밖에서 수정되거나 손상된 복사본도 덮어쓰지 않습니다. 프로그램이 관리하고 내용이 바뀌지 않은 복사본만 원본과 함께 갱신합니다.

환경설정은 파일 저장에 성공한 뒤에만 실행 설정과 단축키에 반영합니다. 저장 오류 뒤 취소하면 기존 설정을 유지합니다. 닫은 설정·단축키·크기 조절·해상도 변환 대화상자는 Qt 객체도 정리합니다.

Pause와 NumLock, PrintScreen과 숫자패드 곱하기는 가상 키 값으로 구분합니다. Qt 입력창의 Print 표기는 저장·실행 시 print screen으로 통일합니다.

스크립트 문법 검사가 지원 명령 여부도 함께 검사합니다. 키보드·문자·left 이외 버튼의 실행 코드는 제거했으며, 같은 문법 검사를 편집기·해상도 변환·실행에서 사용합니다.

메모는 입력 중에도 자동저장합니다. Esc로 편집을 취소하면 편집 전 내용으로 화면·프로필·파일을 함께 되돌립니다. 진행 중인 저장이 있어도 복원 저장이 마지막에 반영됩니다.

단축키 이름은 shortcuts.py에서 통일합니다. 조합 보조키는 Ctrl·Alt·Shift만 지원하며 Win 조합은 저장·실행 검사에서 거절합니다. + 키는 저장 시 plus로 표현하고 입력창에서는 +로 표시합니다. Page Up/PgUp, Page Down/PgDown/PgDn 등은 같은 단축키로 검사하며 프로필 행과 공통 단축키 사이의 중복도 차단합니다. 숫자패드 기호와 일반 키보드 기호는 실제 키 종류와 배열별 보조키를 함께 확인합니다. 마침표는 Delete에 반응하지 않으며, 별표는 Shift 없는 숫자 8에 반응하지 않습니다. 숫자패드 +와 일반 키보드의 =도 구분합니다.

0.2.16-experimental 검증: 실제 입력을 보내지 않는 단위 테스트와 오프스크린 Qt 테스트 270개 통과. 최소화·복원 중 무효 크기 배제, 기준 크기 유지, 복원 후 크기 변경 시 정지 및 클릭·터치 해제를 확인했습니다. 실제 게임 내 입력 동작은 사용자 검증 대상입니다.

대상 창 영역과 편집 도구 줄은 표의 실제 열 폭을 기준으로 정렬합니다. 행 추가·삭제는 왼쪽, 핀·시작 버튼은 오른쪽에 배치하며 창을 넓혀 생기는 여백 때문에 버튼이 이동하지 않습니다. 0.2.18-experimental에서는 UI 테스트 84개와 기본·확장 크기의 화면 표시를 확인했습니다.

대체 좌표는 매번 원본에서 계산하므로 해상도 변경에 따른 반올림 오차가 누적되지 않습니다. 원본 좌표 또는 스크립트 변경 시 다른 캐시를 사용하고, 다시 시작할 때 현재 크기로 대체 좌표를 준비하며, 자동 변환 선택 기억이 꺼져 있으면 변환 방법을 재확인합니다. 실행 중 앱 크기 변경과 최소화 처리 규칙은 유지합니다. 원본 기준 해상도가 없는 경우 자동 변환하지 않습니다. 좌표 캡처는 기존 기준 해상도 혼합 방지 확인 절차를 유지합니다.

0.2.21-experimental에서는 실행 기준을 `ExecutionSession`에 모으고 시작 준비와 명령 생성을 분리했습니다. 앱 정보 자동저장이 자동 변환 선택을 지우지 않으며, 확인창 중 프로필·앱·디스플레이가 변경되면 다시 시작하도록 안내합니다. 특정 디스플레이에서 앱을 선택하지 않은 경우에는 프로필 좌표 변환 화면으로 진행할 수 있습니다. 자동 테스트 291개로 시작·취소·저장 실패·좌표 변환 동등성을 검증했습니다. 실제 게임 입력 동작은 사용자 확인이 필요합니다.

0.2.23-experimental에서는 비율 불일치 차단을 경고로 변경했습니다. 자동 변환은 시작 확인창, 수동 변환은 변환 화면에 같은 기준의 경고를 표시합니다. 수동 저장 직전에도 최신 크기로 변환 결과를 다시 계산합니다. 원본·대상 각각의 정수화 오차를 함께 고려하므로, 반올림된 크기를 기준으로 다시 확대할 때도 불필요한 경고를 줄입니다.

## 자동 변환 선택 기억

시작 전 창 크기 확인창에서 **다음부터 묻지 않기**를 체크하고 **자동 변환으로 시작**을 누르면 `setting.json`의 `auto_convert_on_start`에 선택을 저장합니다. 기본값은 꺼짐입니다. 이후 선택한 앱의 크기가 프로필과 다르면 확인창 없이 메모리 대체 좌표로 시작합니다. 취소·창 크기 변경을 선택하면 이 설정은 바뀌지 않습니다. 환경설정 → 일반 → **창 크기가 다르면 묻지 않고 자동 변환**을 끄면 다시 확인창이 나타납니다.

앱 불일치 알림은 별도 설정이며 계속 적용됩니다. 자동 시작 시 비율 차이가 허용 범위를 넘으면 하단 로그에 경고를 표시합니다. 앱을 선택하지 않은 디스플레이 모드에는 자동 변환 기억을 적용하지 않습니다. 실행 중 크기 변경 정지와 원본 프로필 보존도 유지합니다.

단축키 입력창은 Tab·Shift+Tab·Ctrl+Tab과 Caps Lock도 키로 기록하며 버튼 사이로 포커스를 옮기지 않습니다. Ctrl·Shift·Alt 단독 입력은 키를 놓을 때 지정하고, 다른 일반 키를 함께 누르면 조합키로 지정합니다. Tab·Space는 단독 키 또는 조합의 마지막 키로 사용할 수 있지만 Tab+Q·Space+Q처럼 조합의 보조키로 사용할 수는 없습니다. 이 처리는 행 단축키와 환경설정에 동일하게 적용됩니다. 실행 중 단독 보조키는 누르는 즉시 동작하고 loop 스크립트는 누르는 동안 반복하며 놓으면 반복을 종료합니다. Ctrl 단독과 Ctrl+Q처럼 같은 보조키를 단독·조합에 함께 지정할 수 없습니다. 이 검사는 프로필 행과 공통 시작·정지/좌표 캡처 키 전체에 적용합니다. 충돌한 변경은 저장하지 않고 기존 값을 유지하며 하단 로그에 4초간 안내합니다. Ctrl 단독을 쓰려면 기본 Ctrl+S와 Ctrl+백틱 설정도 다른 키로 바꿔야 합니다. Ctrl 단독과 Alt+Q처럼 다른 보조키를 사용하는 조합은 함께 지정할 수 있습니다. 단축키 등록 중 운영체제의 시스템 키 동작을 차단하는 기능은 추가하지 않았습니다.

## 전체화면 복구 및 미선택 기본값 — 0.2.35-experimental

0.2.34의 앱 필수 실행 변경을 되돌려 0.2.33의 전체화면·디스플레이 설정을 복구했습니다. 미선택과 전체화면을 구분하므로 아무것도 고르지 않은 상태에서 바탕화면 좌표로 실행되지 않습니다. 새 프로필이나 선택한 앱 종료 시 미선택으로 돌아가며, 시작 버튼을 누를 때 앱을 다시 찾아 자동 시작하는 0.2.34 동작은 제거했습니다. 프로필 불러오기 시 저장된 앱 자동 복원은 유지합니다. 독립 터치 스크립트는 이전과 동일하게 앱 선택이 필요합니다.

검증: 자동 테스트 344개 통과. 실제 게임 입력은 수행하지 않았습니다.

## 미선택 자동 검색 및 프로필 앱 변경 선택 — 0.2.36-experimental

미선택 상태에서 시작 버튼 또는 작동/정지 단축키를 누르면 프로필에 기록된 실행 중인 앱을 찾아 선택합니다. 명시적으로 고른 전체화면이나 다른 앱은 자동 검색으로 바꾸지 않습니다. 앱 불일치 시 기본 새 프로필, 현재 내용을 복사한 새 프로필, 현재 프로필 변경을 사용자가 선택합니다. 새 프로필은 정지 상태로 열며 저장 실패 시 기존 프로필을 유지하고 실행하지 않습니다.

검증: 자동 테스트 351개 통과 및 확인창 표시 점검. 실제 게임 입력은 수행하지 않았습니다.

### 입력·프로필·창 크기 변경 오류 방어

프로필의 target_resolution은 `1920x1080`처럼 소문자 x로 구분한 양수 크기 또는 `알 수 없음`을 사용합니다. 다른 형식은 오류로 거부하여 기준 크기가 조용히 사라지거나 자동저장으로 덮어써지지 않게 합니다.

응답 없는 앱은 크기 변경 전에 거부합니다. 크기 변경과 실패 후 복원 요청은 비동기로 보내며, 실제 내부 크기를 제한 시간 안에 확인합니다. 기존 선명도 갱신용 자동 드래그 절차는 유지합니다.
