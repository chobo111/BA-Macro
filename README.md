# BA Macro

Windows용 Python + PySide6 매크로 앱입니다. 단축키로 커서를 이동하거나 스크립트를 독립 터치로 실행합니다.

## 설치 및 실행

Windows 10/11과 Python 3.10 이상이 필요합니다.

1. 이 저장소를 내려받아 압축을 풉니다.
2. `launch.cmd`를 실행합니다. 처음에는 가상환경과 필요한 라이브러리를 설치하므로 인터넷 연결이 필요합니다.
3. 이후에는 생성된 `BA Macro.lnk` 바로가기로 실행합니다.

폴더를 옮겼다면 `launch.cmd`를 다시 실행해 바로가기를 갱신하세요.

## 기본 사용법

1. **대상 앱** 목록에서 실행 중인 앱을 선택합니다.
2. 행을 선택하고 원하는 위치에 커서를 놓은 뒤 `Ctrl+S`로 좌표를 가져옵니다.
3. 행의 단축키와 동작을 지정합니다.
   - **커서 이동**: 저장된 좌표로 실제 커서를 이동합니다.
   - **스크립트**: ‘스크립트 작성’에서 명령을 입력하고 저장합니다. 실행 시 실제 커서를 움직이지 않는 독립 터치를 사용합니다.
4. 재생 버튼이나 Ctrl+백틱으로 활성화한 뒤, 대상 앱에 포커스를 두고 행 단축키를 사용합니다. 같은 버튼이나 단축키로 정지합니다.

대상 앱이 최소화되어 있어도 활성화할 수 있습니다. 최소화 중에는 입력을 보내지 않으며, 복원 후 앱과 해상도 확인을 마쳐야 동작합니다.

대상 앱만 관리자 권한이면 시작 시 BA Macro의 관리자 재실행을 안내합니다. **무시하고 실행**을 선택하면 이번에는 현재 권한으로 시작 절차를 계속합니다. ☰ → 환경설정 → 일반의 **항상 관리자 권한으로 실행**은 기본 OFF이며, 켜면 다음 실행부터 Windows 승인을 요청합니다. 재실행 시 현재 프로필을 저장해 이어서 열고 매크로는 정지 상태로 시작합니다. 승인을 취소하면 기존 앱이 유지됩니다.

행 단축키와 동작은 표에서 변경합니다. 전역 단축키와 클릭 유지 시간 등은 ☰ → 환경설정에서 변경합니다. 메모 내용이 길어지면 메모 열과 표, 상단 영역의 폭이 함께 늘어납니다. 창을 좁히면 표는 가로 스크롤로 볼 수 있습니다.

## 프로필과 좌표

- 표의 변경사항은 자동저장됩니다. 스크립트 초안은 편집창에서 **저장**을 눌러 적용합니다.
- ☰ 메뉴에서 프로필을 생성·불러오기·복제·이름 변경할 수 있습니다. **프로필 선택 → 이 폴더**에는 앱 폴더의 프로필이 표시됩니다.
- 외부 프로필은 앱 폴더에 복사해서 편집합니다. 원본과 기존 동명 파일은 유지되며, 재실행해도 같은 복사본을 엽니다. 변환본 등을 외부에 저장한 경우에도 이후 편집은 앱 폴더의 복사본에 적용됩니다.
- 저장 실패 시 **미저장** 버튼을 눌러 원인을 확인하고 다시 저장할 수 있습니다. 프로필 이름에 마우스를 올리면 현재 파일 경로가 표시됩니다.
- 개인 설정과 프로필은 로컬 JSON 파일에 저장됩니다. 소스 업데이트 전에는 별도로 백업하세요.
- 좌표는 대상 앱의 내부 영역을 기준으로 합니다. 앱 크기가 프로필 기준과 다르면 시작 시 창 크기 변경 또는 자동 변환을 선택할 수 있습니다.
- 수동 좌표 변환은 ☰ → **프로필 해상도 변환**에서 실행합니다.

## 스크립트

한 줄에 명령 하나를 작성하며, 시간 단위는 ms입니다. `mouse`는 명령 실행 시점의 커서 위치를 사용합니다.

```text
loop
click mouse
sleep 100
loop_end
```

`loop` 또는 `loop until_release`는 단축키를 누르는 동안 반복하며, 키를 놓으면 진행 중인 회차를 마치고 멈춥니다. `loop 3`처럼 횟수를 지정하면 키를 놓아도 해당 횟수만큼 실행합니다. 정지하면 진행 중인 대기도 중단합니다.

`click`은 클릭마다 환경설정의 클릭 유지 시간만큼 누른 뒤 뗍니다. 반복 속도에는 `sleep` 외에 이 시간과 입력 처리 시간도 포함됩니다.

대상 앱 영역에서 우클릭하면 편집 위치에 좌표가 들어갑니다. 명령어와 제한사항은 편집창의 **?** 도움말에서 확인할 수 있습니다.

독립 터치는 대상 앱이 터치 입력을 지원해야 합니다. 대상 앱이 포커스를 잃거나 터치 위치가 다른 창에 가려지면 실행이 중단될 수 있습니다.

## 좌표 진단

좌표가 어긋나면 ☰ → **좌표 진단**에서 **기록 시작**을 누른 뒤, 매크로를 활성화하고 대상 앱에서 행 단축키를 누르세요. 다음 동작의 입력을 최대 20개까지 기록합니다. 진단 결과는 파일에 자동 저장하지 않으며 **진단 결과 복사**로 공유할 수 있습니다.

요청 좌표, Windows에 전달한 화면 좌표, 계산 시점과 전송 직전의 앱 위치, 해상도·배율·권한을 비교할 수 있습니다. **커서로 위치 확인**은 매크로를 정지하고 마지막 성공 기록의 앱 내부 좌표로 실제 커서만 옮깁니다. 클릭은 하지 않습니다.

Windows 입력 요청 성공은 게임이 정확한 위치를 처리했다는 뜻이 아닙니다. 게임이 실제 처리한 위치는 확인할 수 없으며, 진단 중 추가 측정으로 입력 간격이 달라질 수 있습니다. 창을 닫으면 기록이 정지됩니다.

## 개발

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

폴더형 EXE 빌드:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller BlueArchiveStudio.spec
```

단일 EXE는 PowerShell에서 `$env:BA_MACRO_ONEFILE = '1'`을 설정한 뒤 같은 빌드 명령을 실행합니다. 빌드가 끝나면 `Remove-Item Env:BA_MACRO_ONEFILE`로 해제합니다.

두 방식 모두 EXE 파일·제품 버전은 `version.py`에서 자동으로 가져옵니다.
