# BA Macro 0.2.65 코드 품질 점검

검토일: 2026-10-13. 기준: main의 0.2.64. 확인된 예외 처리 결함만 수정했다.

## 구조와 검토 범위

- app.py / widgets.py / script_editor.py: PySide6 화면, 행 편집, 설정 및 스크립트 작성.
- engine.py / script_language.py: 단일 입력 작업 스레드, 취소·키 해제·스크립트 실행.
- keyboard_hook.py / mouse_hook.py / touch_input.py / hotkeys.py: 전역 단축키, 외부 우클릭 캡처, 독립 터치.
- domain.py / persistence.py / profile_saves.py: JSON 검증, 원자적 저장, 자동저장 순서와 실패 상태.
- coordinate_transform.py / coordinate_cache.py / conversion*.py / execution_plan.py: 좌표 변환·역변환, 비동기 변환, 실행 기준.
- native.py / interactive_resize.py / single_instance.py / session.py: 창 관리, 크기 변경, 중복 실행 및 편집 상태.

위 주요 경로를 읽고 기존 테스트와 비교했다. 모든 OS·게임 환경을 검증한 것은 아니다.

## 분류와 조치

| 확인된 문제 | 심각도 | 수정 위험도 | 조치 |
|---|---|---|---|
| 키보드 및 외부 우클릭 처리 함수가 예외를 발생시켜도 무시되어 감시 실패가 전달되지 않음 | 중간 | 중간: 입력 생명주기 영향 | 개별 무시 처리를 제거하고 기존 공통 훅 경계에서 실패를 기록하도록 수정 |
| 캡처 가능 여부 검사·터치 필터의 예외가 ctypes 콜백 밖으로 빠져나감. 재현 시 입력 전달 반환값이 기대값과 달라짐 | 높음: 실패 시 입력 전달 결과 불확실 | 중간: 공통 입력 경계 영향 | 예외를 경계 안에서 처리하고 현재 입력과 후속 입력을 다음 훅에 전달 |

두 문제는 같은 예외 경계 누락에서 발생하므로 한 수정 단위로 처리했다. 실패 시 훅 스레드에 종료 메시지를 보내고, 자원을 해제한 뒤 기존 오류 통지를 사용한다. 키보드는 기존 정지 경로, 편집기 캡처는 기존 로그 경로, 터치는 기존 장치 오류 검사로 연결된다. 정상 입력의 매칭·전달 차단 규칙은 유지했다.

## 검증

- 수정 전 전체 553개 테스트 통과.
- 새 회귀 테스트를 수정 전 실행: 키보드 처리, 우클릭 처리, 캡처 조건 검사, 터치 필터의 4개 하위 사례 실패 확인.
- 수정 후 관련 테스트: 훅 생명주기 9개, 우클릭 2개, 단축키 38개, 터치 22개 모두 통과.
- 최종 전체 554개 테스트 통과(18.090초). 실제 입력을 보내지 않는 가짜 Win32 및 Qt 테스트 사용.
- 회귀 테스트는 실패 이벤트 전달, 후속 이벤트 재처리 방지, 훅 해제, 해제 후 단일 오류 통지를 확인.
- git diff --check 통과. macro.json / setting.json의 SHA-256 변경 없음.
- UI 배치·문구·기본값, 프로필 형식, 좌표 변환 규칙은 변경하지 않음.

## 변경하지 않은 부분과 다음 작업 후보

이번 조사에서 성능 개선이나 미사용 코드 삭제의 효과를 확증하지 못한 부분은 유지했다. 코드 스타일 목적의 변경은 하지 않았다.

다음 항목은 확인된 미해결 버그가 아닌 추가 검증 후보다.

1. 실제 게임에서 장시간 반복·앱 전환·최소화와 훅 재시작을 함께 시험하기. 이번에는 실제 게임 입력을 수행하지 않았다.
2. 최대 크기 프로필의 연속 편집·저장 중 UI 응답과 저장 대기 시간을 측정하기. 병목이 측정될 때만 성능 변경을 검토한다.

확인된 수정과 자동 검증을 완료했으며 추가 리팩토링은 진행하지 않는다.
